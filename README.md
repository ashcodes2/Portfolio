## 🛠️ Technology Stack

| Layer | Choice | Why / Function |
|---|---|---|
| **Core Framework** | **React 18 + Vite** | Ultra-fast build times, hot module reloading (HMR) |
| **3D Rendering** | **React Three Fiber (R3F) + Drei** | Seamless React wrapper for Three.js to render 3D scenes |
| **Animations** | **Framer Motion** | Advanced page transitions, scroll-reveals, and gesture micro-interactions |
| **Styling** | **Tailwind CSS v4 + Custom CSS** | CSS-first utility compilation with full design variables configuration |
| **Icons** | **Lucide React + React Icons** | Modern SVG-based clean icon packs |

## ✨ Features & Highlights

* **Interactive 3D Scenes**:
  * Floating abstract 3D geometry with `MeshDistortMaterial` that tracks your mouse movement.
  * A 600-point rotating stellar particle field on the contact form background.
* **Smart UI Elements**:
  * **Adaptive Glassmorphic Header**: Blur-filtered navigation bar that shrinks dynamically on scroll and highlights the currently active section.
  * **Scroll Offset Margin**: Section scroll targets offset perfectly from the sticky navbar so headings are never cut off.
  * **Dual-Direction Marquee**: Fast CSS-only infinite tech-pill slider in the Skills section.
* **Core sections**:
  * **DSA Problem Solving**: Counting counters with custom performance graphs and pattern mastery lists.
  * **Experience Timeline**: Accentuated timeline dots indicating freelance experience.
  * **Live Projects**: Production-grade projects (CollabCode, Vijay Medicals Web App) with exact live demos and source links.
  * **Labs & Experiments**: Section dedicated to works-in-progress like the AI Prompt Enhancer.

## 🚀 Getting Started

To run this portfolio website locally:

### 1. Clone the repository
```bash
git clone https://github.com/ashcodes2/Portfolio.git
cd Portfolio
```

### 2. Install dependencies
```bash
npm install --legacy-peer-deps
```

### 3. Run the development server
```bash
npm run dev
```
Open **[http://localhost:5173](http://localhost:5173)** in your browser!

### 4. Build for production
```bash
npm run build
```
